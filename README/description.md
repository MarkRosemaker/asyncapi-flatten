`asyncapi-flatten` eliminates nesting in [AsyncAPI 3.x](https://www.asyncapi.com/docs/reference/specification/v3.1.0)
specifications. It promotes inline schema definitions, messages, parameters,
and correlation IDs into the top-level `components` section and replaces them
with `$ref` references.
